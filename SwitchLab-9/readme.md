# Lesson 9 : Save Your Work

## Objectif
Comparer la configuration en cours d'exécution (`running-config`) avec la configuration de démarrage (`startup-config`) et rendre les modifications persistantes.

## Commandes apprises
* `show startup-config` : Consulte la configuration enregistrée en NVRAM (utilisée au redémarrage du switch).
* `copy running-config startup-config` : Copie la configuration active vers la mémoire de démarrage afin d'éviter toute perte de données au redémarrage.
