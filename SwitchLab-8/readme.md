# Lesson 8 : Read the Switch - Interfaces

## Objectif
Diagnostiquer l'état physique et administratif des ports du commutateur et réactiver une interface désactivée.

## Commandes apprises
* `show interface status` : Affiche l'état, le VLAN, le duplex et la vitesse de chaque port.
* `show ip interface brief` : Affiche un résumé de l'état administratif (`Status`) et du protocole (`Protocol`) des interfaces.
* `no shutdown` : Active administrativement une interface préalablement éteinte (`g0/3`).
