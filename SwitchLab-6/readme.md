# Lesson 6 : Read the Switch - VLANs

## Objectif
Consulter la table des VLANs pour identifier l'affectation des ports et désactiver administrativement une interface ciblée.

## Commandes apprises
* `show vlan brief` : Affiche la liste des VLANs actifs et les ports qui leur sont attribués.
* `interface g0/1` : Sélectionne le port associé au VLAN 20 (HR).
* `shutdown` : Désactive administrativement l'interface sélectionnée (`administratively down`).
