# Lesson 5 : Type Smart, Not Hard

## Objectif
Utiliser les abréviations de commandes Cisco IOS, gérer les commandes ambiguës et réutiliser l'historique.

## Commandes et astuces apprises
* `en` : Abréviation de `enable`.
* `write memory` : Sauvegarde la configuration active vers la mémoire non volatile (NVRAM).
* **`% Ambiguous command`** : Apparaît lorsqu'une abréviation correspond à plusieurs commandes possibles (ex. `sh st` est ambigu, il faut préciser `sh start` pour `show startup-config`).
* `int g0/2` : Raccourci de `interface g0/2`.
* **Flèche Haut (`Up arrow`)** : Rappelle les commandes précédemment saisies.
